# WytSky / Sky365 Portfolio Knowledge Tree

This folder is the governed entry point for the complete WytSky/Sky365 project and idea portfolio.

## Source of truth

- `master-project-backlog.json` — canonical machine-readable register.
- `SECTOR-HIERARCHY.md` — human-readable sector map.
- `MASTER-PROJECT-BACKLOG.md` — governance and review policy.
- `domains/` — navigable domain and sector tree.
- `templates/PROJECT-README-TEMPLATE.md` — standard project knowledge pack.

## Navigation model

`DOMAIN → SECTOR → SUBSECTOR → PROJECT / CAPABILITY → ITEM`

Each project must have one canonical parent. Cross-sector relationships are represented by links and tags, not duplicate folders.

## Project knowledge pack

A full project folder may contain:

- `README.md` — purpose, scope, current state, parent sector, links.
- `STATUS.md` — status, owner, next action, review trigger.
- `DECISIONS.md` — accepted, rejected, deferred, and superseded decisions.
- `LINKS.md` — repositories, articles, papers, demos, and external references.
- `NOTES.md` — working notes and discoveries.
- `benchmark.json` — machine-readable benchmark data when applicable.

Folders are created when a project needs active documentation. The JSON register remains canonical even when no dedicated project folder exists yet.
